# Livia shop

## Add a product
1. Put the photo in `img/products/` (portrait 4:5, under 200 KB; compress at squoosh.app).
2. Open `products.js` and copy one block inside PRODUCTS, put it at the TOP, and change:
   id (unique), name, category, price, image (file name), options, desc.
3. Save, upload to GitHub. Done. Categories and filters appear by themselves.

## First-time settings (top of products.js)
Shop name, WhatsApp number (like 201012345678), delivery fee, free-delivery amount.

## Go online (free)
GitHub > new public repo > upload everything in this folder > Settings > Pages > Deploy from branch > main > root.
Your shop opens at https://USERNAME.github.io/REPO/. Add a custom domain later in the same Pages settings.
